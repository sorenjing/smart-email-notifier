# Smart Email Notifier

一个用于**重要邮件筛选与行动提醒**的通用 ChatGPT Skill。

> **告诉 ChatGPT 你不想错过什么。Skill 负责设计筛选策略、调用当前可用能力，并只在登录、验证或敏感授权等必要环节让你接管。**

[English](./README.md) · [Skill](./SKILL.md) · [QQ 邮箱 → Gmail → ChatGPT 示例](./docs/qqmail-gmail-chatgpt.md)

## 为什么做它

真正重要的邮件经常和广告、Newsletter、普通系统通知混在一起；纯关键词规则也不够可靠——重要邮件可能只写“下一轮安排已更新”，宣传邮件却可能包含大量“面试”“笔试”等关键词。

因此 Smart Email Notifier 使用两层判断：

```text
邮箱规则宽召回 → AI 语义判断 → 只提醒真正需要处理的事项
```

> **邮箱规则负责别漏掉，AI 负责别烦你。**

## 怎么用

安装或提供 [`SKILL.md`](./SKILL.md) 后，直接描述你的需求：

```text
帮我配置秋招重要邮件提醒。
```

```text
工作会议有改期、取消或者需要我提前准备时提醒我。
```

```text
学校邮件里有考试、作业或需要我处理的通知时提醒我。
```

Skill 会根据场景和当前环境能力决定配置方式：生成合适的邮箱筛选策略和 AI 判断规则；能够通过已连接邮箱、任务等能力完成的步骤尽量直接完成；必须由本人完成的登录、验证码、2FA、CAPTCHA 或敏感授权则交还给用户。

## 它能帮你处理什么

根据邮箱能力和当前可用工具，Skill 可以帮助设计或配置：

- 文件夹 / 标签；
- 主题、正文、发件人等匹配字段；
- 包含任一、包含全部、排除等匹配逻辑；
- 召回关键词与排除词；
- 选择性转发或路由；
- AI 语义判断策略；
- Deadline、事项时间和下一步动作提取；
- 定时或条件检查；
- 端到端验证。

Skill 本身不会凭空获得邮箱或浏览器权限。实际自动化程度取决于当前 ChatGPT 环境、已连接服务和用户授权。

## 真实案例：秋招邮件

这个项目最初来自一个真实问题：招聘宣传、笔试、测评、面试、HR 待办和 Offer 相关邮件全部混在同一个邮箱里。

我实际使用的一条链路是：

```text
QQ 邮箱
→ 宽召回规则
→ 选择性转发 Gmail
→ ChatGPT 语义判断
→ 真正需要操作时才提醒
```

通用 Skill 并不绑定 QQ 邮箱或秋招；这只是一个经过脱敏的使用示例。具体过程见 [QQ 邮箱 → Gmail → ChatGPT 示例](./docs/qqmail-gmail-chatgpt.md)，场景策略见 [`presets/`](./presets/)。

## 适用场景

求职、工作与会议通知、学校 Deadline、账单与续费、订单异常、账号安全，以及任何“不能漏掉真正需要处理的邮件”的自定义场景。

## 隐私与安全

优先使用选择性转发，不要默认把整个私人邮箱交给 AI。不要向 Skill 提供邮箱密码、短信验证码、恢复码、App Password、Token 或 Cookie。

公开截图和示例应使用虚构身份与链接，并移除真实邮箱、手机号、候选人/账号 ID、私人笔试/面试/会议链接、授权信息、二维码和包含身份参数的 URL。

## 当前范围

V1 是一个可复用 Skill，而不是独立邮箱软件。不同邮箱和 ChatGPT 环境的能力并不一致，因此当某一步无法自动完成时，Skill 会退化为最短的人工配置指引，而不是假装已经执行成功。
