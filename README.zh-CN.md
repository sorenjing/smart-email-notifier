# Smart Email Notifier

一个用于**重要邮件筛选与行动提醒**的通用 ChatGPT Skill。

> **告诉 ChatGPT 你不想错过什么。Skill 会根据场景生成筛选与判断策略，并在当前环境已经提供相应能力且获得授权时协助完成配置；需要登录、验证或敏感授权的步骤始终由用户本人确认。**

[English](./README.md) · [Skill](./SKILL.md) · [QQ 邮箱 → Gmail → ChatGPT 示例](./docs/qqmail-gmail-chatgpt.md)

## 为什么做它

真正重要的邮件经常和广告、Newsletter、普通系统通知混在一起；纯关键词规则也不够可靠——重要邮件可能只写“下一轮安排已更新”，宣传邮件却可能包含大量“面试”“笔试”等关键词。

因此 Smart Email Notifier 使用两层判断：

```text
邮箱规则宽召回 → AI 语义判断 → 只提醒真正需要处理的事项
```

> **邮箱规则负责别漏掉，AI 负责别烦你。**

## 怎么用

安装或提供 [`SKILL.md`](./SKILL.md) 后，直接描述你的需求，例如：

```text
帮我配置秋招重要邮件提醒。
```

```text
工作会议有改期、取消或者需要我提前准备时提醒我。
```

```text
学校邮件里有考试、作业或需要我处理的通知时提醒我。
```

Skill 会根据场景生成建议的邮箱筛选策略和 AI 判断规则。在当前 AI 助手已经提供邮箱读取、任务等能力且用户已授权时，可使用这些现有能力协助完成相应步骤；否则会给出必要的人工配置指引。

## 主要功能

根据邮箱服务商、当前 AI 环境和用户授权情况，Skill 可以帮助：

- 设计文件夹 / 标签和邮件路由策略；
- 生成主题、正文、发件人等匹配规则；
- 选择“包含任一 / 包含全部 / 排除”等匹配逻辑；
- 生成召回关键词与排除词；
- 设计选择性转发方案；
- 生成 AI 语义判断策略；
- 提取邮件中明确给出的 Deadline、事项时间、链接和下一步动作；
- 在环境支持时配置定时或条件检查；
- 协助验证整条提醒链路。

## 真实案例：秋招邮件

这个项目最初来自一个真实问题：招聘宣传、笔试、测评、面试、HR 待办和 Offer 相关邮件全部混在同一个邮箱里。

我实际使用的一条链路是：

```text
QQ 邮箱
→ 宽召回规则
→ 选择性转发 Gmail
→ ChatGPT 语义判断
→ 真正需要操作时才提醒
```

通用 Skill **不要求用户使用 QQ 邮箱、Gmail 或 ChatGPT**；这只是一个经过脱敏的示例。具体过程见 [QQ 邮箱 → Gmail → ChatGPT 示例](./docs/qqmail-gmail-chatgpt.md)，场景策略见 [`presets/`](./presets/)。

## 适用范围

适合求职、工作与会议通知、学校 Deadline、账单与续费、订单异常、账号安全，以及其他“不能漏掉真正需要处理的邮件”的场景。

它更适合**辅助筛选和提醒**，不应作为法律、医疗、金融、安全事件或其他高风险事项的唯一通知渠道。

## 能力与限制

为避免误解，请在使用前了解：

- Skill 是一组可复用的 AI 工作流指令，**不是独立运行的邮箱软件或后台服务**；
- Skill 本身不会获得新的邮箱、浏览器、账号或任务权限；
- 实际可执行能力取决于用户使用的 AI 助手、客户端、地区、邮箱服务商、已连接服务和授权状态；
- 如果某一步缺少可用工具，Skill 会改为提供人工配置指引；
- 邮箱服务商界面、规则和第三方 AI 能力可能发生变化，示例无法保证永久与当前界面一致；
- AI 对邮件的分类、时间和行动项提取可能出现误判或遗漏，重要事项仍应由用户核对原始邮件；
- 不保证任何特定邮件一定被召回、识别或及时提醒。

## 隐私与安全

优先使用选择性转发，不要默认把整个私人邮箱交给 AI。请仅授权完成目标所必要的邮箱范围，并自行确认所使用邮箱、AI 助手及其他第三方服务的条款和隐私政策。

**不要向 Skill 提供邮箱密码、短信验证码、恢复码、App Password、Token、Cookie、私钥或其他秘密凭证。** Skill 不应绕过登录、CAPTCHA、2FA、权限控制或服务商的安全机制。

公开截图和示例应使用虚构身份与链接，并移除真实邮箱、手机号、候选人/账号 ID、私人笔试/面试/会议链接、授权信息、二维码和包含身份参数的 URL。
