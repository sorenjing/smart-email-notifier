# QQ 邮箱 → Gmail → ChatGPT 配置指南

> 这是 `smart-email-notifier` 的一个具体适配案例。核心 Skill 不依赖 QQ 邮箱或 Gmail。

![脱敏流程演示](../assets/qqmail-gmail-chatgpt-demo.svg)

## 0. 为什么先建文件夹？

建议先在 QQ 邮箱中新建一个专用文件夹，例如求职场景使用 `求职`。它不是自动提醒的必要条件，但有三个好处：便于人工复查、方便观察规则是否漏信/误判、即使转发链路临时失效也能在 QQ 邮箱里找到原邮件。

因此推荐顺序是：

```text
新建文件夹 → 新建收信规则 → 移动到文件夹 + 自动转发 → 手机验证 → Gmail 接受转发 → ChatGPT 连接 Gmail → 创建提醒任务
```

## 1. 新建专用文件夹

QQ 邮箱中进入文件夹管理，新建一个与场景对应的文件夹。

求职示例：`求职`

其他场景也可以是 `学校通知`、`账单`、`会议`、`Important-AI`。

## 2. 新建收信规则

进入 QQ 邮箱的收信规则设置，新建规则。求职场景可以先使用较宽松的关键词：

```text
面试 / 笔试 / 测评 / 在线测评 / 人才测评
初试 / 复试 / 校招 / 秋招 / 招聘
录用 / offer / Offer / 签约 / 背调 / 候选人 / 下一轮
```

可以分别在主题、正文、附件名中配置。第一层的目标是提高召回率，不要为了减少误报把规则收得太窄。

执行动作建议同时设置：

- `移动到 → 求职`
- `自动转发到 → yourname@gmail.com`
- 保留原邮件

> `yourname@gmail.com` 只是文档示例，请替换为你自己的目标邮箱。

## 3. 完成 QQ 邮箱人工验证

保存自动转发规则时，QQ 邮箱可能要求手机号验证。这一步由用户本人在 QQ 邮箱页面完成。

不要向 AI、教程作者或第三方提供邮箱密码、短信验证码、授权码或 App Password。

## 4. 在 Gmail 接受转发

规则保存后，Gmail 会收到 QQ 邮箱生成的自动转发验证邮件。打开该邮件，根据邮件中的官方提示点击 `接受转发`，完成授权。

如果没有收到：

1. 检查垃圾邮件；
2. 检查 QQ 邮箱规则中的目标 Gmail 地址；
3. 确认 QQ 邮箱规则已保存并启用。

## 5. 连接 Gmail 与 ChatGPT

在 ChatGPT 中连接 Gmail。连接完成后，先使用一封无敏感信息的测试邮件验证是否能够检索到目标邮件，再创建自动检查任务。

## 6. 创建 AI 提醒任务

求职场景可以使用：

```text
检查我的已连接邮箱中自上次检查以来的新邮件。

重点识别与求职和招聘相关、并且真正需要我采取行动或会改变申请状态的邮件，包括笔试、在线测评、面试、HR 沟通、Offer、签约、背调、明确截止日期以及其他候选人操作事项。

对每个需要关注的新事项，尽可能提取：公司、岗位、事项类型、具体时间、截止时间、相关链接、我需要完成的动作、紧急程度。

过滤广告、Newsletter、普通招聘宣传、重复转发和不需要我采取行动的信息。只有发现新的、需要关注或操作的事项时才提醒我。如果存在明确截止时间，突出剩余时间和下一步动作。如果邮件没有提供日期、截止时间或链接，不要自行猜测。
```

高时效场景可以在白天检查多次；账单等低时效场景通常每天一次即可。

## 7. 验证整条链路

不要配置完就默认成功。使用无敏感信息的测试邮件验证：

```text
QQ 邮箱收到邮件
  ↓
规则命中并进入专用文件夹
  ↓
Gmail 收到转发
  ↓
ChatGPT 可以检索
  ↓
AI 正确判断是否需要提醒
```

## 为什么不是只用关键词？

关键词只适合做粗筛。例如：

- `下一轮安排已更新` 可能很重要，但没有出现“面试”；
- `XX 公司秋招正式启动` 可能包含大量求职关键词，却不需要你立即操作。

所以这个项目采用两层设计：

> **邮箱规则负责别漏掉，AI 负责别烦你。**

## 发布截图前的隐私检查

公开教程、视频或 README 中不要出现真实的：

- QQ / Gmail 完整地址；
- 手机号、验证码；
- 姓名、候选人 ID；
- 私人笔试 / 测评 / 面试链接；
- 会议邀请链接；
- token、cookie、授权码、二维码。

本仓库演示图统一使用 `example@qq.com`、`yourname@gmail.com` 和 `https://example.com/...` 等占位信息。
